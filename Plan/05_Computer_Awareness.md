## Computer Knowledge — Complete Syllabus

### Topic 1: Computer Fundamentals (Week 1 of Computer study)

**1.1 History & Generations**

| Generation | Period | Technology | Example |
|-----------|--------|-----------|---------|
| 1st | 1940–56 | Vacuum Tubes | ENIAC, UNIVAC |
| 2nd | 1956–63 | Transistors | IBM 7090 |
| 3rd | 1964–71 | Integrated Circuits | IBM 360 |
| 4th | 1971–present | Microprocessors | Personal computers |
| 5th | Present-future | AI, parallel processing | Supercomputers |

**1.2 Types of Computers**
- **Supercomputer:** Fastest, scientific calculations (e.g., PARAM Shakti, India)
- **Mainframe:** Large organizations, banking backend systems
- **Minicomputer:** Mid-range, departmental use
- **Microcomputer:** Personal computers, desktops, laptops
- **Embedded:** Computers inside appliances (ATMs, washing machines)

**1.3 Hardware: Input Devices**

| Device | Function |
|--------|---------|
| Keyboard | Text/number input |
| Mouse | Pointing and clicking |
| Scanner | Converts physical documents to digital |
| Webcam | Video input |
| Microphone | Audio input |
| Barcode Reader | Reads barcodes (used in retail, banking) |
| OCR | Optical Character Recognition |
| OMR | Optical Mark Recognition (used in exams!) |
| Touchscreen | Both input and output |

**1.4 Hardware: Output Devices**

| Device | Function |
|--------|---------|
| Monitor (VDU) | Display output |
| Printer | Hard copy output (Laser, Inkjet, Dot matrix) |
| Speakers | Audio output |
| Projector | Large-scale display output |
| Plotter | Prints large technical drawings |

**1.5 CPU (Central Processing Unit)**
- **ALU (Arithmetic Logic Unit):** Does all math and logical operations
- **CU (Control Unit):** Controls sequence of operations, manages CPU
- **Registers:** Tiny, fastest storage inside CPU
- **Cache Memory:** Very fast memory between CPU and RAM (L1, L2, L3 cache)
- Clock Speed measured in GHz (higher = faster)

**1.6 Memory Types**

| Type | Full Form | Volatile? | Editable? | Use |
|------|-----------|----------|----------|-----|
| RAM | Random Access Memory | Yes (loses data on power off) | Yes | Temporary working memory |
| ROM | Read Only Memory | No | No (read-only) | BIOS, firmware |
| Cache | — | Yes | Yes | Fastest buffer between CPU & RAM |
| Virtual Memory | — | Yes | Yes | Disk space used as extra RAM |

**1.7 Storage Devices**

| Device | Type | Speed | Capacity |
|--------|------|-------|---------|
| HDD | Hard Disk Drive | Slow-Medium | 500 GB–20 TB |
| SSD | Solid State Drive | Fast | 128 GB–4 TB |
| CD-ROM | Optical | Slow | 700 MB |
| DVD | Optical | Slow | 4.7–8.5 GB |
| Pen Drive / USB | Flash | Medium | 4 GB–1 TB |
| Cloud Storage | Online | Depends on internet | Unlimited |

**Storage Units to Memorize:**
```
8 bits = 1 Byte
1024 Bytes = 1 KB (Kilobyte)
1024 KB = 1 MB (Megabyte)
1024 MB = 1 GB (Gigabyte)
1024 GB = 1 TB (Terabyte)
1024 TB = 1 PB (Petabyte)
```

### Topic 2: Operating Systems (3–4 days)

**What is an Operating System?**  
The OS is the **interface between the user and the hardware**. Without an OS, a computer is useless. It manages all resources.

**Types of OS:**
- **Windows** (Microsoft): Most common for personal computers
- **Linux/Unix:** Open-source, used in servers and banking backend systems
- **Mac OS** (Apple): Premium personal computers
- **Android** (Google): Mobile OS (Linux-based)
- **iOS** (Apple): iPhone/iPad OS

**Functions of OS:**
1. **Memory Management:** Allocates RAM to programs
2. **Process Management:** Manages running programs (processes)
3. **File Management:** Organizes files and folders
4. **Device Management:** Manages printers, keyboard, etc.
5. **Security:** User authentication, access control
6. **Error Detection:** Identifies hardware/software errors

**Important OS Concepts:**
- **Booting:** Starting the computer (Cold boot = full restart, Warm boot = restart while on)
- **GUI:** Graphical User Interface — uses icons, windows, mouse (Windows, Mac)
- **CLI:** Command Line Interface — uses text commands (Linux terminal)
- **Multitasking:** Running multiple programs simultaneously
- **Time-Sharing:** Multiple users share CPU time (server environments)
- **File Systems:** FAT32 (older), NTFS (Windows), ext4 (Linux), HFS+ (Mac)

### Topic 3: MS Office (3–4 days)

**MS Word (Word Processing)**
- **File format:** .doc (older), .docx (current)
- Create, edit, format text documents
- Common shortcuts: Ctrl+B (Bold), Ctrl+I (Italic), Ctrl+U (Underline), Ctrl+S (Save), Ctrl+P (Print), Ctrl+Z (Undo), Ctrl+Y (Redo), Ctrl+A (Select All), Ctrl+C (Copy), Ctrl+V (Paste), Ctrl+X (Cut)

**MS Excel (Spreadsheet)**
- **File format:** .xls (older), .xlsx (current)
- Organized in **Rows** (numbered: 1, 2, 3...) and **Columns** (lettered: A, B, C...)
- **Cell:** Intersection of a row and column (e.g., A1, B3)
- **Common Formulas:** =SUM(A1:A10), =AVERAGE(B1:B5), =COUNT(C1:C8), =MAX(), =MIN()
- Used in banking for data analysis, MIS reports

**MS PowerPoint (Presentations)**
- **File format:** .ppt (older), .pptx (current)
- Content organized in **Slides**
- **Slide Show:** Fullscreen presentation mode (F5 to start)
- **Transitions:** Effects between slides
- **Animations:** Effects on individual elements within a slide

**MS Access (Database — occasionally asked)**
- Relational database management system
- Used to store and retrieve structured data
- **Tables, Forms, Queries, Reports** are main components

### Topic 4: Internet & Networking (3–4 days)

**Internet Basics:**
- **WWW (World Wide Web):** System of interlinked web pages (≠ Internet itself)
- **Internet:** Global network of computers — WWW is a service on it
- **HTTP:** HyperText Transfer Protocol — transfers web pages
- **HTTPS:** Secure version of HTTP (S = SSL/TLS encryption) — used in banking!
- **URL:** Uniform Resource Locator — web address (e.g., https://rbi.org.in)
- **IP Address:** Unique numerical address for every device on internet (e.g., 192.168.1.1)
- **Domain Name:** Human-readable address (e.g., google.com) — DNS converts it to IP
- **Browser:** Software to access the web: Chrome, Firefox, Edge, Safari, Opera

**Email Components:**
- **SMTP:** Simple Mail Transfer Protocol — sends email (outgoing)
- **POP3:** Post Office Protocol — downloads email to device
- **IMAP:** Internet Message Access Protocol — syncs email across devices

**Types of Networks:**
| Network | Full Form | Coverage | Example |
|---------|-----------|---------|---------|
| LAN | Local Area Network | Single building/room | Office network |
| MAN | Metropolitan Area Network | City | City-wide cable TV network |
| WAN | Wide Area Network | Countries/continents | Internet |
| PAN | Personal Area Network | Few meters | Bluetooth devices |

**Network Devices:**
- **Router:** Connects different networks, routes data packets — the device at home for WiFi
- **Switch:** Connects multiple devices in a LAN
- **Hub:** Like a switch but broadcasts to all devices (less efficient)
- **Modem:** Converts digital signals to analog (for DSL/cable internet) and vice versa
- **Repeater:** Boosts signal for longer distances
- **Gateway:** Entry/exit point between networks

**Wireless Technologies:**
- **WiFi (802.11):** Wireless LAN — uses radio waves
- **Bluetooth:** Short-range wireless (up to 10 meters) — for headphones, keyboards
- **4G LTE:** Mobile network standard (download ~50 Mbps)
- **5G:** Next-gen mobile network (download ~1 Gbps)
- **NFC:** Near Field Communication — used in contactless payments (tap and pay)

### Topic 5: Cybersecurity (2–3 days)

**Types of Threats:**

| Threat | What it does |
|--------|-------------|
| **Virus** | Attaches to files, spreads when file is opened, corrupts data |
| **Worm** | Self-replicates across networks without needing a host file |
| **Trojan Horse** | Appears legitimate, hides malware — disguised as useful software |
| **Ransomware** | Encrypts your files, demands ransom to unlock them (e.g., WannaCry) |
| **Spyware** | Secretly monitors and collects user data |
| **Adware** | Displays unwanted ads, often bundled with free software |
| **Phishing** | Fraudulent emails/websites that trick users into giving passwords |
| **Keylogger** | Records keystrokes to steal passwords and credit card details |
| **DoS Attack** | Denial of Service — floods a server, making it unavailable |

**Protection Measures:**
- **Antivirus Software:** Detects and removes viruses (e.g., Norton, McAfee, Kaspersky)
- **Firewall:** Monitors incoming/outgoing network traffic, blocks unauthorized access
  - Can be hardware (router-level) or software (Windows Defender Firewall)
- **Encryption:** Converting data to unreadable format — only decrypted with a key
  - **SSL/TLS:** Used in HTTPS for secure web transactions — crucial for banking
  - **AES:** Advanced Encryption Standard — used for file encryption
- **Two-Factor Authentication (2FA):** Password + OTP = extra security layer
- **VPN:** Virtual Private Network — encrypts internet connection, masks IP address

**Important Terms:**
- **Malware:** Umbrella term for all malicious software
- **Hacker types:** White hat (ethical), Black hat (criminal), Grey hat (in between)
- **Ethical Hacking / Penetration Testing:** Legal testing of systems for vulnerabilities
- **Digital Signature:** Proves authenticity and integrity of digital documents (used in banking)
- **PKI (Public Key Infrastructure):** System for managing digital certificates

### Topic 6: Database Basics (2 days — mainly for IBPS PO Mains)

**What is a Database?**
An organized collection of structured data — like a digital filing system.

**DBMS vs RDBMS:**
- **DBMS:** Database Management System — manages any structured data
- **RDBMS:** Relational DBMS — data stored in tables with relationships between them
- Examples: MySQL, Oracle, Microsoft SQL Server, PostgreSQL

**Basic SQL Commands (for awareness — not deep exam focus):**
- `SELECT` — Retrieves data from a table
- `INSERT` — Adds new records
- `UPDATE` — Modifies existing records
- `DELETE` — Removes records
- `CREATE TABLE` — Creates a new table
- `DROP TABLE` — Deletes a table

**Key Database Terms:**
- **Table:** Like a spreadsheet — rows and columns
- **Row / Record / Tuple:** One entry in the table (one person's data)
- **Column / Field / Attribute:** One type of information (Name, Age, etc.)
- **Primary Key:** Unique identifier for each row (e.g., customer ID, account number)
- **Foreign Key:** Links two tables together
- **Query:** A question asked to the database to retrieve data

### Topic 7: Number Systems (2–3 days)

**Why computers use Binary:** Computers only understand ON/OFF (1/0) — this is binary.

| System | Base | Digits Used | Prefix |
|--------|------|------------|--------|
| Decimal | 10 | 0–9 | None |
| Binary | 2 | 0, 1 | 0b |
| Octal | 8 | 0–7 | 0 |
| Hexadecimal | 16 | 0–9, A–F | 0x |

**Key Conversions:**

Decimal 10 → Binary:
- 10 ÷ 2 = 5 remainder 0
- 5 ÷ 2 = 2 remainder 1
- 2 ÷ 2 = 1 remainder 0
- 1 ÷ 2 = 0 remainder 1
- Read remainders bottom to top: **1010** ✅

Hexadecimal shortcut:
- A=10, B=11, C=12, D=13, E=14, F=15
- 1F in hex = (1×16) + (15) = 31 in decimal
