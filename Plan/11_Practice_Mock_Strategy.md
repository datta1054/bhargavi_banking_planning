# 11 · Practice Question Strategy, PYQ Strategy & Mock Test Framework
### How to Practice Effectively and Analyze Every Mock Test

---

## 11.1 The Practice Question Philosophy

There is a critical difference between **"completing" practice** and **"learning" from practice**. Many students solve hundreds of questions but don't improve because they:
- Check only the answer (right/wrong) without understanding the solution.
- Practice only topics they're already comfortable with.
- Never revisit questions they got wrong.
- Don't time themselves.

**This section eliminates all of those mistakes.**

---

## 11.2 Practice Question Framework — 3-Layer Approach

### Layer 1: Conceptual Practice (Phase 1–2)
**Purpose:** Understand the topic, not race the clock  
**Quantity:** 15–25 questions per topic session  
**Time:** No timer — understand fully first  
**Method:**
1. Study the concept/formula.
2. Solve 3–5 solved examples from a book.
3. Attempt 10–15 unsolved questions on your own.
4. Check ALL answers — understand every error, not just count errors.
5. Re-solve wrong questions after understanding the correct method.

### Layer 2: Timed Topic Practice (Phase 2–3)
**Purpose:** Build speed while maintaining accuracy  
**Quantity:** 30–40 questions per session  
**Time:** Set a timer (1 minute/question for easy, 2 minutes/question for medium)  
**Method:**
1. Start the timer.
2. Solve the set.
3. Stop when timer ends — mark where you reached.
4. Check answers.
5. Calculate: Accuracy % and Attempted %.
6. Record in your Progress Tracker.

### Layer 3: Full Mock Practice (Phase 3–4)
**Purpose:** Simulate real exam conditions  
**Quantity:** Full exam-pattern tests  
**Time:** Exactly as per exam timing  
**Method:** Full mock test protocol (see Section 11.5)

## 11.4 Previous Year Question Paper (PYQ) Strategy

### Why PYQs Are Non-Negotiable

Previous year papers are the **most reliable indicator** of what will appear in your exam. Questions often repeat with slight variations. Patterns become clear. By solving 5+ years of PYQs, you train your brain to recognize exam-style questions and solve them faster.

### PYQ Schedule

| Exam | Years to Cover | When to Start | Total Papers |
|------|---------------|--------------|-------------|
| IBPS PO Prelims | 2017–2025 | Phase 3 (Feb 2027) | 8–9 papers |
| IBPS PO Mains | 2017–2025 | Phase 3 (Feb 2027) | 8–9 papers |
| IBPS Clerk Prelims | 2017–2025 | Phase 3 (Feb 2027) | 8–9 papers |
| IBPS Clerk Mains | 2018–2025 | Phase 3 (Mar 2027) | 7–8 papers |
| IBPS RRB PO Prelims | 2018–2025 | Phase 3 (Feb 2027) | 7–8 papers |
| IBPS RRB Clerk Prelims | 2018–2025 | Phase 3 (Feb 2027) | 7–8 papers |
| Karnataka Bank | Available papers | Phase 3–4 | 3–5 papers |

### PYQ Solving Method

**Step 1: Solve Under Exam Conditions**
- Strict timing (60 min for Prelims, as per exam pattern).
- No interruptions, no phone.
- Attempt realistic number of questions (don't attempt all — be selective as in real exam).

**Step 2: Score and Section Analysis**
```
After each PYQ paper, record:
- Total Score: ___/100
- QA: Attempted ___ | Correct ___ | Accuracy ___% | Time ___min
- Reasoning: Attempted ___ | Correct ___ | Accuracy ___% | Time ___min
- English: Attempted ___ | Correct ___ | Accuracy ___% | Time ___min
- Were all sectional cutoffs met? Yes / No
```

**Step 3: Error Categorization**
For every wrong answer, classify as:
1. **Conceptual error** — Didn't know the method → Revise the topic.
2. **Calculation error** — Knew method but made arithmetic mistake → Practice more carefully.
3. **Reading error** — Misread the question → Work on reading questions twice.
4. **Time pressure error** — Guessed incorrectly due to time running out → Improve time management.

**Step 4: Pattern Recognition**
After solving 3+ years of PYQ from same exam, note:
- Which topics appear every year? (Tier 1 topics — must ace)
- Which topics appear occasionally? (Tier 2 — should know)
- Which question types are most common?
- What difficulty level is the exam?

## 11.6 Mock Test Analysis Framework (CRITICAL)

The analysis AFTER a mock test is more important than the mock test itself. Here is the complete 8-step analysis framework:

### Step 1: Record Your Raw Score (5 minutes)
```
Date: ___________  Mock No.: ___  Platform: _______________
Total Score: ___/100  Time taken: ___min
QA: ___/35  |  Reasoning: ___/35  |  English: ___/30
Sectional Cutoff Cleared: QA(Y/N)  Reasoning(Y/N)  English(Y/N)
```

### Step 2: Time Distribution Analysis (10 minutes)

Calculate how much time you spent on each section:
- Did you distribute time well?
- Which section took too long?
- Did you rush through English to save time for QA?

**Target time distribution (Prelims, 60 min):**
- QA: 20 minutes
- Reasoning: 22 minutes  
- English: 18 minutes

### Step 3: Question-by-Question Review (30–40 minutes)

Go through EVERY question:
- Mark each as: ✅ Correct | ❌ Wrong | ⏭️ Skipped
- For every ❌: Find the correct answer and understand WHY.

### Step 4: Categorize Mistakes (10 minutes)

```
QA Errors:
- Conceptual: ___ questions (Topics: _______________)
- Calculation: ___ questions
- Reading error: ___ questions
- Time error: ___ questions

Reasoning Errors:
- Puzzle approach wrong: ___ questions
- Conceptual: ___ questions
- Time error (guessed): ___ questions

English Errors:
- Grammar rule unknown: ___ questions
- Vocabulary unknown: ___ questions
- RC comprehension issue: ___ questions
```

### Step 5: Attempted vs. Accuracy Analysis (5 minutes)

| Section | Attempted | Correct | Accuracy |
|---------|----------|---------|---------|
| QA | | | |
| Reasoning | | | |
| English | | | |

**Ideal:** Attempt 25–28 QA, 25–28 Reasoning, 22–24 English with 80%+ accuracy

### Step 6: Question Selection Review (5 minutes)

- Did you attempt the right questions? (easy ones first)
- Did you waste time on difficult questions that should have been skipped?
- Which questions should you have skipped to save time for easier ones?

### Step 7: Speed Analysis (5 minutes)

- Average time per question per section
- Which types of questions took longest?
- Where were you fastest?

### Step 8: Action Plan for Next Week (5 minutes)

Based on analysis, write:
1. **Top 2 weak topics to revise this week:** ___________
2. **Speed to improve for:** ___________
3. **Strategy change for next mock:** ___________

> **Total Analysis Time:** 60–70 minutes for a proper analysis  
> **This is NOT optional.** An unanalyzed mock test is wasted.

## 11.7 Your Attempt Strategy for the Real Exam

### Question Selection Philosophy

Banking prelims exams have sectional time limits. You **cannot** attempt every question perfectly. You need a selection strategy.

### The 3-Round Attempt Strategy

**Round 1: Quick Wins (First 8–10 minutes per section)**
- Go through all questions quickly.
- Attempt only those you can answer in 30–45 seconds.
- Mark the rest for Round 2.
- Goal: Get easy marks quickly without wasting time.

**Round 2: Medium Difficulty (Next 8–10 minutes per section)**
- Return to marked questions.
- Attempt those you can do in 1.5–2 minutes.
- Skip anything that needs complex calculation or long puzzle reading first.

**Round 3: Tough/Remaining (Last 2–3 minutes)**
- Very quick attempt on remaining.
- Guess strategically on questions where you can eliminate 2 wrong options.
- Leave questions where you have no idea (to avoid negative marking).

### Section-Specific Strategy

**QA Prelims Strategy:**
- Start with: Simplification, Approximation, Quadratic Equations (fastest — 30 seconds each)
- Then: Number Series (1 minute each)
- Then: Word problems (P&L, SI, TSD — 1.5–2 min each)
- Last: DI sets (5–7 min per set — attempt 1–2 sets only if time permits)

**Reasoning Prelims Strategy:**
- Start with: Inequalities (15–20 seconds each), Alphanumeric Series, Direction Sense
- Then: Syllogisms, Blood Relations, Coding-Decoding
- Last: Puzzles and Seating (10–12 min per set — attempt 1–2 sets first, come back)

**English Prelims Strategy:**
- Start with: Error Detection, Fill in the Blanks (30 seconds each)
- Then: Cloze Test (read once, answer 5 questions — 4 min)
- Last: Reading Comprehension (start reading only if 8+ minutes remain)

## 11.8 Speed Building Drills — Daily Practice

### QA Speed Drills (10 minutes/day from Phase 2)

**Drill 1 — Simplification Sprint:**
- 25 simplification questions
- Target: All 25 in 8 minutes
- Do this EVERY morning before main study session (warms up the math brain)

**Drill 2 — Multiplication Speed:**
- Practice: 2-digit × 2-digit multiplication mentally
- Examples: 43 × 27, 68 × 54, 91 × 36
- Target: 10 such multiplications in 3 minutes

**Drill 3 — Fraction-Percentage Conversion:**
- Random fraction to percentage: 7/8 = ?%, 5/6 = ?%, 3/11 = ?%
- Learn these by heart: 1/7 = 14.28%, 1/8 = 12.5%, 1/9 = 11.11%, etc.

### Reasoning Speed Drills (10 minutes/day from Phase 2)

**Drill 1 — Inequality Speed:**
- 20 inequality questions (symbol-based)
- Target: All 20 in 4 minutes
- These should eventually take 10–15 seconds each

**Drill 2 — Syllogism Speed:**
- 15 syllogism questions
- Target: All 15 in 6 minutes
- Use shortcut rules after learning Venn diagram method
