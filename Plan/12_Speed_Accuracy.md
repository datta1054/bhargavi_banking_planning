## 12.1 The Speed-Accuracy Balance

The most dangerous mistake in banking exam preparation is optimizing for speed at the expense of accuracy. With negative marking (−0.25 per wrong answer), a wrong answer doesn't just give you 0 — it costs you 1.25 marks (you lose the 1 mark for the correct answer + 0.25 penalty).

### The Mathematics of Negative Marking

```
Scenario: You attempt 30 questions in QA (35 total, 20 min)

Case A: High Speed, Low Accuracy
→ Correct: 18 | Wrong: 12
→ Score: 18 − (12 × 0.25) = 18 − 3 = 15

Case B: Moderate Speed, High Accuracy
→ Correct: 22 | Wrong: 3 | Skipped: 5
→ Score: 22 − (3 × 0.25) = 22 − 0.75 = 21.25

Winner: Case B scores 42% MORE than Case A
```

**Lesson:** It is always better to attempt fewer questions correctly than many questions incorrectly.

|---------|---------------|-----------------|
| QA (35 total) | 22–26 | 80%+ |
| Reasoning (35 total) | 22–26 | 82%+ |

## 12.3 Speed Techniques for Quantitative Aptitude

### Technique 1: Vedic Math for Multiplication
**Fast multiplication using the FOIL-like method:**

Example: 47 × 53
- Split: (50–3)(50+3) = 50² − 3² = 2500 − 9 = 2491

Example: 23 × 27 (both have same tens digit, units add to 10)
- Answer: (2)(3) | (7) = 621 (tens digit × next number | units product)
- 23 × 27 = 2×3 hundreds + 3×7 = 600 + 21 = 621 ✅

### Technique 2: Approximation Over Exact Calculation

For questions asking "approximately how much?" — never calculate exactly.

Example: 48.9% of 318.7 = ?
→ Approximate: 49% of 319 ≈ 50% of 319 − 1% of 319 ≈ 159.5 − 3.19 ≈ 156.3
→ This takes 20 seconds vs. 90 seconds for exact calculation

**When to approximate:** Any question with "approximately" in it, and DI questions where you need only one or two decimal place accuracy.

### Technique 3: Percentage-Based Shortcuts

**Percentage of a number:**
- 10% of X = X/10 (just move decimal)
- 5% = half of 10%
- 25% = X/4
- 33.33% = X/3
- 15% = 10% + 5%
- 12.5% = 10% + 2.5%

Example: 15% of 840 = 84 + 42 = 126 (10% + 5%) — done in 5 seconds

### Technique 4: Ratio-Based Approach for P&L, SI/CI

Instead of using formulas blindly, convert to ratio thinking:

**SI Example:** Principal = 12,000, Rate = 8%, Time = 3 years
→ SI = 12000 × 8 × 3 / 100 = 12000 × 24 / 100 = 2880
→ Faster: 1% of 12000 = 120, so 24% = 24 × 120 = 2880 (same answer, faster process)

### Technique 5: Elimination in Data Interpretation

For DI questions with big numbers:
- **Never calculate exact values** when relative comparison is asked
- **Use approximation aggressively:** 
  - 48,321 ≈ 48,000 (or even 50,000 for rough comparison)
  - "Which year had highest ratio?" — compare approximate values, not exact

### Technique 6: Unit Digit Trick for Powers

For questions asking unit digit of a large power:
- Unit digit of any power depends ONLY on the unit digit of the base
- 7¹ = 7, 7² = 9, 7³ = 3, 7⁴ = 1, then repeats (cycle of 4)
- Similarly: 2 (2,4,8,6 cycle), 3 (3,9,7,1 cycle), 4 (4,6 cycle), 6 (always 6)

## 12.4 Speed Techniques for Reasoning

### Technique 1: Puzzle Pre-Reading Strategy

Before starting a puzzle:
1. Read all clues once (20–30 seconds) — don't try to solve yet
2. Identify: How many entities? How many attributes?
3. Choose your representation: table, line, or circles
4. Start filling with the most definite clue

**Time saved:** Pre-reading prevents you from having to re-read clues repeatedly.

### Technique 2: Seating Arrangement — Clockwise/Anticlockwise Clarity

The most common error in circular seating is mixing up clockwise and anticlockwise.

**Rule:** In a circular arrangement, if no direction mentioned for "left/right" — assume facing center.
- Person A's LEFT = the person sitting to the left when A faces center
- In a circle: 1 position to A's right = going clockwise

**Practice drawing:** Draw 6 circles → Place N, E, W, S, NE, NW seats → Practice placing people without confusing left/right.

### Technique 3: Syllogism — Use Shortcuts After Venn Diagrams

Learn these shortcuts after understanding the Venn diagram method:

| Statement | Valid Conclusion |
|-----------|-----------------|
| All A → B | Some B → A (valid) |
| All A → B + All B → C | All A → C (valid) |
| Some A → B + All B → C | Some A → C (valid) |
| No A → B | No B → A (valid) |
| Some A → B + No B → C | Some A → not C (valid) |

Memorizing these patterns allows you to answer syllogisms in 20–25 seconds each.

### Technique 4: Coding-Decoding — Code the Pattern First

Before trying to decode: spend 15 seconds finding the pattern.
- Is it letter shifting? (A→D means +3 shift)
- Is it reversal? (A→Z means reverse alphabet)
- Is it position-based? (A=1, B=2...)
- Is it word-to-symbol mapping?

Once you find the pattern, all 4–5 questions in that set become trivial.

### Technique 5: Inequality — Direct Application

For symbol-based inequalities, memorize one rule:

If A > B > C: A > C is definitely true, A < C is definitely false
If A > B ≥ C: A > C is definitely true
If A = B > C: A > C is definitely true
If A > B, C > B: No direct relationship between A and C

Practice 50 inequality sets — they become reflex responses in 10–15 seconds.

## 12.5 Speed Techniques for English

### Technique 1: Error Detection — Rule-Based Scanning

Instead of reading the sentence for "feel," develop a systematic scan:

**Error Detection Scan Checklist (15 seconds per sentence):**
1. Check Subject-Verb Agreement (singular subject = singular verb?)
2. Check Tense consistency (all verbs in same tense?)
3. Check Article usage (A/An/The correct?)
4. Check Pronoun agreement (matches the noun in number?)
5. Check Preposition (common wrong prepositions: "discuss about" ❌, "discuss" ✅)
6. Check Redundancy ("return back" ❌, "return" ✅)

With practice, this checklist runs automatically in 10–12 seconds.

### Technique 2: Reading Comprehension — Skimming vs. Scanning

**Skim** (first 60 seconds): Read topic sentence of each paragraph — get the structure
**Scan** (for specific answers): Look for keywords from the question in the passage

For factual questions: Scan → find the specific sentence → answer
For inference questions: Must read that paragraph fully
For main idea questions: Trust your skim understanding

### Technique 3: Cloze Test — Elimination Method

For each blank in a cloze test:
1. Read the sentence around the blank
2. Identify: noun/verb/adjective/adverb needed?
3. Eliminate options that are wrong parts of speech
4. Among remaining: which fits the meaning + grammar?

This eliminates guessing and increases accuracy significantly.

### Technique 4: Para Jumbles — Find the Fixed Sentences First

1. Look for the opening sentence (no pronoun without antecedent, no "however/but/also")
2. Look for the closing sentence (often a conclusion, summary, or consequence)
3. Look for consecutive pairs (a sentence with "It/This/These" must follow the sentence that introduces "It")
4. Build the sequence around these anchors

## 12.6 Accuracy Improvement — Error Analysis System

### The Error Notebook (Must Have from Day 1)

Buy a dedicated notebook for errors. Every time you get a question wrong:

```
Question: _______________________________________________
My Answer: _____  Correct Answer: _____

Why I got it wrong:
□ Didn't know the concept
□ Knew concept but calculation error
□ Misread the question
□ Guessed wrong (time pressure)
□ Knew concept but applied wrong formula

What I should remember next time:
_______________________________________________

Similar question type to practice: _______________
```

Review your error notebook **every Saturday** for 20 minutes.

### The 4-Type Error Classification (from [11_Practice_Mock_Strategy.md#11.6](file:///c:/Users/gadde/Desktop/Bhargavi/bhargavi_banking_planning/Plan/11_Practice_Mock_Strategy.md#11.6) expanded)

**Type 1 — Conceptual Errors (most serious)**
- Action: Revisit the concept, understand from scratch, solve 10 more questions of that type
- Root cause: Insufficient concept practice

**Type 2 — Calculation Errors**
- Action: Practice mental math, check work when time permits
- Root cause: Rushing, not double-checking
- Fix: For high-stakes questions (5+ marks type), spend 10 extra seconds to verify

**Type 3 — Reading Errors**
- Action: Slow down on question reading (not answer solving)
- Root cause: Reading the question too fast
- Fix: Read question → Underline key information → Then solve

**Type 4 — Time Pressure Errors (guessing)**
- Action: Improve speed on easier question types to create time buffer
- Root cause: Poor question selection in the exam
- Fix: Practice the 3-round attempt strategy

## 12.8 Psychological Speed: Managing Exam Anxiety

Speed in the exam is not just technical — it's psychological. Anxiety slows down thinking.

**Signs of Exam Anxiety:**
- Mind goes blank when reading a question
- Forgetting formulas you know perfectly at home
- Re-reading the same question 4–5 times without processing

**Solutions:**
1. **Breathing technique:** If you feel panic, take 3 deep breaths (4 seconds inhale, 4 hold, 6 exhale)
2. **Skip and return:** Don't fixate on one question — skip it, come back
3. **Mock test simulations:** The more mock tests you take, the less anxious you'll be in the real exam
4. **Visualization:** Before sleeping, spend 2 minutes visualizing yourself calmly solving questions in the exam hall
